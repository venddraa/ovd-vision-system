# Data Manifests

Folder ini hanya menyimpan metadata yang aman untuk version control, seperti:

- source dan owner;
- URL referensi;
- license dan allowed use;
- tanggal diperoleh;
- dataset version;
- class map;
- jumlah file/anotasi;
- checksum;
- duplicate groups;
- exclusion list;
- split manifest;
- sensitivity classification.

Raw image/video, annotation sensitif, physical ground truth individual, dan model artifact disimpan di `../storage/` di luar repository Git.
